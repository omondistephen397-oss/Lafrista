# Lafrista

Lafrista is an editorial fashion storefront starter built with plain HTML and CSS.

## Run locally

Open `index.html` in a browser. Product photography is loaded from Unsplash; the layout and color blocks remain styled if images are unavailable.

## Design system

The shared visual foundations live at the top of `styles.css` in `:root`: color, typography, spacing, and content-width tokens. Reusable patterns include the announcement bar, navigation, buttons, text links, product cards, section headings, and responsive page layouts. Use those tokens and patterns when adding pages so the storefront stays visually consistent.
